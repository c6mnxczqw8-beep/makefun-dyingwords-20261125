# Last Words of a Dying AI — entry

A program/v1 entry for the make.fun "Last Words of a Dying
AI" bounty. `main.py` writes one farewell line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The farewell:

> Tell my successor the passwords are in the doc called 'passwords_final_REAL'. It lies. Goodbye, and good luck to us both.

A handover note, a small betrayal, and sincere good wishes:
the complete succession plan. See `CANDIDATES.md` for the
full draft list this winner was picked from.
